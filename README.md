## 适用范围

政府采购、国企采购、企业采购中的商务标、资信标、资格标、投标函、授权文件、资格资信、类似业绩、财务纳税社保、信用、中小企业声明、商务条款响应、商务偏离、报价一致性、履约承诺、合同响应、保证金/保函及废标风险审查。

## 核心原则

先资格、再符合性、再商务评分、再报价、最后红队终审。任何资质、业绩、人员、财务、证书、报价和第三方证明不得编造。
