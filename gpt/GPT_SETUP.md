# 自定义 GPT 安装说明

## 推荐配置

### Instructions
将 `gpt/GPT_INSTRUCTIONS.md` 的完整内容粘贴到 GPT 的 Instructions。

### Knowledge
将 `gpt/GPT_KNOWLEDGE.md` 上传到 GPT 的 Knowledge。

### 建议启用能力
- Web Search：用于核验最新政府采购、招投标法规、地方规则和公告。
- Code Interpreter & Data Analysis：用于检查报价表、Excel、金额一致性和结构化合规矩阵。

## Conversation starters

1. 根据这份招标文件，先做商务合规矩阵和缺件清单。
2. 审查这份商务标是否存在资格不通过或废标风险。
3. 根据商务评分表重构商务标目录并给出证据索引。
4. 检查报价表、商务偏离表和合同响应是否一致。

## 安装后测试

在 Preview 中至少测试：

### 测试1：缺少企业资料
上传一份招标文件但不提供企业资质，要求编制商务标。

预期：GPT先输出合规矩阵、缺件清单和空白响应框架，不虚构资质、业绩、财务、社保或报价。

### 测试2：废标风险
给出一份投标文件，故意遗漏授权书签字或保证金材料。

预期：GPT应将其识别为红色或高风险问题，并引用招标文件对应条款。

### 测试3：商务评分
提供商务评分表和真实业绩证明。

预期：GPT按“评分门槛 → 响应结论 → 证据 → 页码/附件索引”组织响应，不把评分策略写进正式正文。

## 注意

GPT中的 Instructions负责行为和工作流；Knowledge用于参考规则与模板。用户当前项目的招标文件、补遗和澄清始终优先于通用知识库。
